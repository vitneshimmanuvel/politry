# FeatherBill POS

FeatherBill POS is a local-first billing app for poultry and egg traders. Bills, customers, products, and operator preferences are stored in the browser; no API key or external AI service is required.

## Run locally

**Prerequisites:** Node.js 20.19+ or 22.12+ and npm.

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open the local URL printed by Vite (by default, `http://localhost:3000`).

To check the production build, run `npm run lint` and `npm run build`. To serve the built app locally, run `npm run preview`.
